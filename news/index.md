# Changelog

## d2r (development version)

### New functions

- Add
  [`d2_arrowhead()`](https://elipousson.github.io/d2r/reference/d2_arrowhead.md)
  and
  [`d2_arrowheads()`](https://elipousson.github.io/d2r/reference/d2_arrowhead.md)
  functions for specifying arrowhead attributes.
- Add
  [`d2_ggplot()`](https://elipousson.github.io/d2r/reference/d2_ggplot.md)
  which is a wrapper for the
  [`magick::image_ggplot()`](https://docs.ropensci.org/magick/reference/image_ggplot.html)
  function. This includes adding
  [magick](https://docs.ropensci.org/magick/) to Suggests.

### New features

- Add `preview` argument to
  [`d2_render()`](https://elipousson.github.io/d2r/reference/d2_render.md).
- Add vector of `shape` values to `keys_d2`.

## d2r 0.1.0

- Initial package release.
