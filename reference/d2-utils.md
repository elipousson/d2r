# Basic D2 utilities

Basic D2 utilities

- `d2_which()`: List path for D2

&nbsp;

- `d2_version()`: List the installed version of D2

&nbsp;

- `d2_themes()`: List available D2 themes

&nbsp;

- `d2_layout()`: Lists available layout engine options with short help

&nbsp;

- `d2_validate()`: List the installed version of D2

## Usage

``` r
d2_which()

d2_version()

d2_themes()

d2_layout(layout = NULL)

d2_validate()
```

## Arguments

- layout:

  Layout name. If supplied, display long help for a particular layout
  engine, including its configuration options.
